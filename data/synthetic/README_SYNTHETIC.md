# ТОЛЬКО СИНТЕТИКА
Все продукты, бренды, цены, показатели маржи, популярности, пользовательские запросы и поведенческие события в этой папке **полностью вымышлены** и предназначены исключительно для локального прототипирования. Они не происходят от организаторов, реальных пользователей или заказчика. Значения синтетических цен/маржи нельзя использовать для бизнес-выводов. Набор маленький, оценка на нём не является показателем качества на реальном каталоге.

`catalog_synthetic.json`: каталог 30 вымышленных ПО; `synonyms_synthetic.json`: словарь; `eval_queries_synthetic.json`: список 36 разметок с ожидаемыми ID (включая отсутствие результата); `behavior_events_synthetic.json`: искусственные сигналы поведения, **случайные и не привязанные к запросам**; они годятся для проверки ingestion/analytics, но не для обучения релевантности или настоящих статистических выводов.
